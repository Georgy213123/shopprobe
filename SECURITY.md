# Политика безопасности

## Что это за код

Репозиторий демонстрационный: все данные, компании и цифры вымышлены, внешние сервисы
заменены заглушками, ключей и реальных учётных данных здесь нет и быть не должно.
Значения в `.env.example` — учебные и нигде не действуют.

## Как сообщить об уязвимости

Если нашли уязвимость в коде или случайно попавший секрет, не открывайте публичный issue.
Напишите через [приватное сообщение об уязвимости](https://github.com/Georgy213123/shopprobe/security/advisories/new)
на GitHub. Отвечу в течение трёх рабочих дней.

## Что проверяется автоматически

| Проверка | Где |
|---|---|
| Поиск секретов в истории и в каждом коммите (gitleaks) | pre-commit, CI |
| Аудит зависимостей Python (pip-audit) и npm (`npm audit --audit-level=high`) | CI, `make audit` |
| Статический анализ (CodeQL) | CI, еженедельно и на PR |
| Обновление зависимостей (Dependabot) | ежемесячно |

## Правила для кода

- Конфигурация только через переменные окружения; `.env` в `.gitignore`.
- Пароли хранятся хешем (Argon2/bcrypt), токены с ограниченным сроком.
- Ввод пользователя валидируется на границе API (pydantic), вывод экранируется во фронте.
- SQL только через ORM или параметризованные запросы.
