# 06. Баги

Пять показательных, у каждого тест, красный без исправления. BUG-01 — известная ловушка: тест
написан сразу, дефект воспроизведён откатом к наивной версии.

## BUG-01. Lazy-картинки ниже экрана считались битыми

- Симптом: исправная картинка с `loading="lazy"` под первым экраном — «Битая картинка».
- Причина: критерий `naturalWidth === 0`, а lazy-картинку браузер ещё не грузил. Перепроверка не спасала.
- Фикс: прокрутка до конца, ожидание `complete`; битая — только `complete` и `naturalWidth === 0`.
- Тест: `probe/tests/browser/checks.test.ts` → BUG-01, `probe/tests/unit/images.test.ts`.

## BUG-05. Длинное название давало скролл на 390 px, детектор не называл виновника

- Симптом: на чистой витрине скролл на `/catalog` в мобильном, «виновник: не определён». Дефект настоящий.
- Причина: слово «Ферментированный» шире колонки; детектор смотрел только на блоки, а вылезал текст.
- Фикс: перенос слов в CSS; детектор ищет элемент с `scrollWidth > clientWidth`.
- Тест: `checks.test.ts` → BUG-05, `e2e/tests/storefront.spec.ts` → «нет горизонтального скролла».

## BUG-06. Витрина упала после первого визита — приёмка зелёная

- Симптом: перепроверки получили отказ соединения, исходная находка «не подтвердилась».
- Причина: перепроверка учитывала только отпечатки исходных находок, новый сбой навигации отбрасывался.
- Фикс: сбои, появившиеся при перепроверке, идут в отчёт со своим вердиктом (`probe/src/run.ts`).
- Нашёл Codex (R2). Тест: `probe/tests/browser/review.test.ts` → R2.

## BUG-07. Перепроверка и проверки раскладки не видели прокрутки

- Симптом: ошибка консоли от прокрутки давала 0 из 3; подгруженный прокруткой h1 не проверялся.
- Причина: прокрутка жила в проверке картинок, а перепроверка гоняла только проверку с находкой.
- Фикс: прокрутка вынесена в подготовку визита до всех проверок, перепроверка гоняет все.
- Нашёл Codex (R3, R8). Тест: `review.test.ts` → R3, R8.

## BUG-09. Под дев-сервером Vite терялись все ошибки консоли приложения

- Симптом: `make probe` по `make dev` не нашёл ошибку виджета отзывов.
- Как нашли: сверил отчёт со скриншота с мета-тестом, который её находит на `vite preview`.
- Причина: Vite оборачивает `console.error`, и источник любой ошибки — `/@vite/client`. Фильтр BUG-04
  отсекал всё с этим источником.
- Фикс: отсекаются только известные сообщения клиента HMR (`probe/src/checks/console.ts`).
- Тест: `checks.test.ts` → BUG-09, `probe/tests/unit/console.test.ts` → BUG-09.
