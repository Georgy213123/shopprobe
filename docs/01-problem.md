# 01. Постановка

«Чайная полка» — вымышленный магазин чая: около 30 товаров, каталог с фильтрами, корзина.
Выкатка раз-два в неделю, два разработчика и владелец, тестировщика нет. Цифры — допущения.

| Боль | Допущение «до» |
|---|---|
| Мобильную вёрстку после выкатки первыми видят сломанной покупатели | 2–3 дефекта в неделю |
| Битые картинки и ошибки в консоли живут на сайте | около 2 дней |
| Ручная приёмка на двух устройствах | 40 мин, 5–6 страниц |
| Первые скрипты сообщают о дефектах, которых нет | около половины находок |

Последняя строка главная: отчёт с половиной ложных находок владелец перестаёт читать.
Поэтому каждая находка перепроверяется.

Владелец читает отчёт, разработчик повторяет находку по шагам, CI падает на подтверждённых.

## Успех

- К1. Прогон на 1440×900 и 390×844 — меньше 3 минут, без ручных действий.
- К2. На чистой витрине ноль подтверждённых находок.
- К3. С `SEEDED_BUGS=1` найдены все посаженные дефекты, нестабильный запрос не подтверждён.
- К4. В находке есть страница, вьюпорт, шаги и статус перепроверки.
- К5. Другая витрина подключается правкой конфига.

Вне рамок — нереализованные модули из [README](../README.md).
