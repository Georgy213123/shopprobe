# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [1.0.1] — 2026-11-04

Исправления по ревью Codex gpt-6.1-sol (R1…R11 в docs/04-ai-development.md).

### Fixed
- BUG-06: сбой навигации при перепроверке попадает в отчёт; упавшая витрина больше не даёт зелёную приёмку (R2).
- BUG-07: прокрутка вынесена в подготовку визита до всех проверок; перепроверка гоняет все проверки (R3, R8).
- BUG-08: запрет localStorage не роняет витрину (R9).
- Отпечаток HTTP — путь без query и класс ответа; отпечаток axe — правило и узлы (R4, R7).
- Конфиг: повтор имени вьюпорта и неверные `failOn`, `minImpact` — ошибка (R5, R6).
- Шаблоны игнора с флагами `g`/`y` срабатывают каждый раз (R10).
- Порты Docker-стенда опубликованы только на 127.0.0.1, пароль PostgreSQL из окружения (R1).

### Changed
- `make test` работает на `TEST_DATABASE_URL` (по умолчанию `shopprobe_test`); фикстура
  отказывается работать на базе без суффикса `_test`, dev-база больше не стирается.
- Тест пагинации проверяет, что страницы не пересекаются (R11).
- e2e: в CI (`CI=1`) оставленный `test.only` роняет прогон.

## [1.0.0] — 2026-11-03

### Added
- Мета-тест ShopProbe в `make e2e`: на чистой витрине ноль подтверждённых находок,
  на `SEEDED_BUGS=1` найдены все посаженные дефекты, нестабильный запрос не подтверждён.
- Сбой самой проверки даёт находку critical с целью `probe-error`.
- CLI-тест: ShopProbe запускается через `npx tsx`, как у пользователя.
- Цель `make probe` — прогон по запущенной витрине.

### Fixed
- BUG-04: ошибки клиента HMR Vite и расширений браузера больше не считаются ошибками витрины;
  источник `pageerror` берётся из стека.
- BUG-05: длинные названия товаров переносятся; детектор скролла называет элемент,
  чьё содержимое шире блока.
- Функции для `page.evaluate` не используют именованные вложенные функции (сбой `__name` под tsx).
- Каталог: выбор фильтра отмечается сразу, прежний список виден, пока грузится новый.

## [0.4.0] — 2026-10-30

### Added
- Перепроверка каждой находки N раз в новом контексте браузера; вердикты
  «подтверждено», «нестабильно», «не подтвердилось».
- HTML-отчёт: карточки сводки, таблица с шагами воспроизведения и статусом перепроверки.
- Порог `failOn` и коды выхода 0/1/2.

### Fixed
- BUG-02: проверки ждут устоявшуюся страницу (`load`, сеть, шрифты, два кадра).

## [0.3.0] — 2026-10-27

### Added
- Проверка доступности на axe-core с уровнями серьёзности и порогом `minImpact`.
- Демо-витрина «Чайная полка»: API каталога с фасетами (FastAPI, PostgreSQL),
  фронт на React с корзиной в localStorage.
- Флаг `SEEDED_BUGS=1` и семь посаженных дефектов.

### Fixed
- BUG-03: счётчик фасетной группы не учитывает фильтр своей же группы.

## [0.2.0] — 2026-10-24

### Added
- Вьюпорты 1440×900 и 390×844.
- Проверки горизонтального скролла и единственного h1.
- `report.json`.

### Fixed
- BUG-01: lazy-картинки ниже экрана подгружаются прокруткой; битой считается
  только загруженная и не декодированная.

## [0.1.0] — 2026-10-21

### Added
- Визит страницы в новом контексте браузера; проверки консоли, HTTP ≥ 400, битых картинок.
