# Требования

MoSCoW. Тесты — в [матрице](../05-testing.md#матрица-трассировки).

## Функциональные

| ID | Требование | Пр. | Как проверяется |
|---|---|---|---|
| FR-01 | Главная ведёт в каталог по типу чая | M | e2e `US-01`: «Улун» → `category=oolong`, 4 товара |
| FR-02 | Фильтры витрины, состояние в URL | M | `category=green&origin=china&origin=japan` → 5 товаров |
| FR-03 | Фасетный счётчик группы считается по всем фильтрам, кроме своего | M | при «Зелёный» у «Чёрный» по-прежнему 6 |
| FR-04 | Карточка товара по адресу `/product/<slug>`, неизвестный slug — 404 | M | `test_us03_product_card`, `test_product_not_found`, e2e `US-03, US-04` |
| FR-05 | Корзина в localStorage с итогом | M | e2e: две штуки → 1 520 ₽ |
| FR-06 | Конфиг и флаги CLI | M | `config.test.ts` |
| FR-07 | Проверки консоли, HTTP, картинок, скролла, h1 | M | браузерные тесты на фикстурах |
| FR-08 | Доступность через axe-core с порогом | M | фикстура с низким контрастом |
| FR-09 | Перепроверка, три вердикта | M | запрос «через раз» → нестабильно |
| FR-10 | Отчёт JSON и HTML с шагами и статусом | M | unit отчёта, CLI-тест |
| FR-11 | Код выхода 1 при подтверждённой не ниже `failOn`; 3, если таких нет, но приёмка неполная (страница не открылась или упала проверка, BUG-11); 2 при ошибке конфига | S | CLI-тест, `cli.test.ts` → SP-02 |
| FR-12 | Посаженные дефекты по `SEEDED_BUGS=1` | M | мета-тест |
| FR-13 | Сбой самой проверки — находка critical | S | `probe/tests/browser/cli.test.ts` |
