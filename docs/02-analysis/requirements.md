# Требования

Приоритет — MoSCoW: **M** — must, **S** — should, **C** — could, **W** — won't (в этой версии).
Критерий проверки — то, по чему требование считается выполненным; где это автотест,
он указан в [матрице трассировки](../05-testing.md#матрица-трассировки).

## Функциональные: демо-витрина «Чайная полка»

| ID | Требование | Пр. | Критерий проверки |
|---|---|---|---|
| FR-01 | Каталог: список товаров с сортировкой (популярные, цена ↑↓, название) и пагинацией | M | `GET /api/catalog?sort=price_asc&per_page=5&page=2` — цены по возрастанию, `total` = всем товарам |
| FR-02 | Фильтры: тип чая, страна, форма (мультивыбор), цена от/до, «только в наличии». Состояние — в URL | M | фильтр `category=green&origin=china&origin=japan` даёт 5 товаров; перезагрузка и «назад» сохраняют выбор |
| FR-03 | Фасетные счётчики: у каждого значения — число товаров. Группа считается по всем фильтрам, кроме своего | M | после выбора «Зелёный» у «Чёрный» по-прежнему 6, у «Япония» — 2 |
| FR-04 | Карточка товара: название, страна, форма, вес, цена, описание, картинка | M | `GET /api/products/{slug}` 200 и 404 на неизвестный slug; e2e открывает карточку из каталога |
| FR-05 | Корзина в localStorage: добавить, изменить количество (1…20), удалить, итог. Без оформления и оплаты | M | e2e: две штуки → итог 1 520 ₽, количество 3 → 2 280 ₽, перезагрузка не теряет корзину |
| FR-12 | Посаженные дефекты по флагу `SEEDED_BUGS=1`: битая картинка, ошибка в консоли, 404 стиля, горизонтальный скролл на 390 px, два h1, низкий контраст кнопки, нестабильный запрос | M | без флага — ни одного; с флагом — каждый виден ShopProbe (мета-тест) |

## Функциональные: ShopProbe

| ID | Требование | Пр. | Критерий проверки |
|---|---|---|---|
| FR-06 | Настройка в `probe.config.ts`: BASE_URL, маршруты, вьюпорты (по умолчанию 1440×900 и 390×844), пороги; флаги CLI перекрывают файл | M | юнит-тесты `resolveConfig`: значения по умолчанию, слияние, отказ на неверном конфиге |
| FR-07 | Проверки страницы: ошибки консоли и JS, ответы ≥ 400 у документа и ресурсов, битые картинки (naturalWidth = 0), горизонтальный скролл, ровно один h1 | M | браузерные тесты на фикстурах: каждая проверка ловит свой дефект и молчит на чистой странице |
| FR-08 | Доступность через axe-core (WCAG 2.0/2.1 A и AA) с уровнем серьёзности из axe; ниже `minImpact` не сообщаем | M | фикстура с низким контрастом даёт `color-contrast`, serious |
| FR-09 | Перепроверка: каждая находка повторяется N раз в чистом контексте; вердикт «подтверждено / нестабильно / не подтвердилось» | M | фикстура с запросом «через раз» — нестабильно; 404 скрипта — подтверждено 3 из 3 |
| FR-10 | Отчёт: `report.json`, `report.html` (таблица: страница, вьюпорт, находка, подробности, шаги воспроизведения, статус перепроверки) и сводка в консоль | M | юнит-тесты отчёта, CLI-тест пишет оба файла |
| FR-11 | Код выхода для CI: 1 при подтверждённой находке не ниже `failOn`, 2 при ошибке запуска | S | CLI-тест: дефектная страница → 1; нестабильные находки приёмку не валят |
| FR-13 | Сбой самой проверки — находка critical, а не тихий пропуск | S | CLI-тест под tsx: `probe/tests/browser/cli.test.ts` (история в [04-ai-development](../04-ai-development.md)) |
| FR-14 | Визуальная регрессия, производительность, SEO, сценарии оплаты, ночной прогон, агентный разбор отчёта | W | вне рамок демо, см. карту модулей в README |

## Нефункциональные

| ID | Требование | Пр. | Критерий проверки |
|---|---|---|---|
| NFR-01 | Прогон 6 маршрутов × 2 вьюпорта с перепроверкой — меньше 3 минут на ноутбуке разработчика | M | время в [отчёте прогона](../05-testing.md#отчёт-прогона) |
| NFR-02 | Нет ложных срабатываний: на чистой витрине ноль подтверждённых находок | M | мета-тест в `make e2e` |
| NFR-03 | Работа без сети и ключей: только локальный Chromium Playwright, axe-core — библиотека | M | весь `make e2e` идёт на localhost |
| NFR-04 | Неверные параметры API — 422 с описанием, не 500; лишние параметры запрещены | M | интеграционные тесты: `price_min > price_max`, неизвестный параметр |
| NFR-05 | Контракт API в `docs/03-design/openapi.yaml` совпадает с кодом | S | `test_openapi_file_matches_code` |
| NFR-06 | Чистая витрина соответствует WCAG 2.1 AA: ноль нарушений axe уровня serious и выше | S | мета-тест на чистой витрине |
| NFR-07 | Отчёт экранирует всё, что пришло со страницы: текст ошибки не исполняется как HTML | M | юнит-тест `экранирует текст со страницы` |
| NFR-08 | Воспроизводимость: lock-файлы у всех пакетов, Playwright закреплён точной версией | S | `uv.lock`, `package-lock.json`, `playwright@1.62.1` |
