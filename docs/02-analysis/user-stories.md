# Пользовательские истории

US-01…US-04 — покупатель витрины, US-05…US-09 — разработчик или владелец, который принимает релиз.

**US-01. Начать с типа чая** (FR-01).
- **Given** главная, **When** выбираю «Улун», **Then** открыт каталог с фильтром `category=oolong`, «Найдено: 4».

**US-02. Подобрать чай фильтрами** (FR-02, FR-03).
- **Given** каталог, **When** отмечаю «Зелёный», **Then** «Найдено: 5», у «Чёрный» по-прежнему 6.
- **Given** выбраны фильтры, **When** перезагружаю страницу, **Then** выбор сохранён.

**US-03. Посмотреть карточку** (FR-04).
- **Given** каталог, **When** открываю «Сенча утренняя», **Then** адрес `/product/sencha-utrennyaya`, цена 760 ₽.
- **Given** несуществующий адрес товара, **When** API запрашивает карточку, **Then** ответ 404.

**US-04. Собрать корзину** (FR-05).
- **Given** карточка, **When** дважды нажимаю «Добавить в корзину», **Then** итог 1 520 ₽.
- **Given** мусор в localStorage, **When** открываю витрину, **Then** корзина пустая, страница работает.

**US-05. Приёмка одной командой** (FR-06…FR-08, NFR-01).
- **Given** запущенная витрина, **When** запускаю `make probe`, **Then** за 3 минуты получаю `report.html`.

**US-06. Без ложных дефектов** (FR-09, NFR-02).
- **Given** запрос, падающий через раз, **When** идёт перепроверка, **Then** он «нестабильно» и приёмку не валит.
- **Given** lazy-картинки и шум HMR, **When** идёт прогон, **Then** находок нет.

**US-07. Понять находку по отчёту** (FR-10, NFR-07).
- **Given** прогон завершился, **When** открываю `report.html`, **Then** вверху итог «пройдена / не пройдена / неполная», подтверждённые и серьёзные первыми, у каждой находки вьюпорт, шаги и вердикт перепроверки.
- **Given** на странице текст с HTML, **When** он попал в находку, **Then** в отчёте он виден как текст.

**US-08. Остановить выкатку в CI** (FR-11).
- **Given** подтверждённая находка не ниже `failOn`, **When** CI запускает ShopProbe, **Then** код выхода 1.
- **Given** подтверждённых нет, но одна страница не открылась, **When** прогон закончился, **Then** код 3 и «Приёмка: неполная», а не зелёный итог.

**US-09. Проверить сам инструмент** (FR-12).
- **Given** `SEEDED_BUGS=1`, **When** идёт мета-тест, **Then** найдены все шесть стабильных дефектов, лишних нет.
