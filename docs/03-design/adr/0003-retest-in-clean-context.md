# ADR-0003. Перепроверка находок в чистом контексте и три вердикта

- Статус: принято
- Дата: 2026-10-23

## Контекст и проблема

Главная претензия владельца к автоматике — ложные дефекты. Источников два: нестабильность
самой витрины (сетевой запрос падает через раз) и нестабильность замера (проверка сработала
до того, как страница устоялась). Нужно, чтобы в «чинить» попадало только воспроизводимое.

## Рассмотренные варианты

1. Ретраи на уровне раннера тестов (как `retries` в Playwright Test): упал — повторить весь прогон.
2. Перепроверка каждой находки отдельно, N раз, в новом контексте браузера; вердикт по доле воспроизведений.
3. Один прогон, ручная разметка ложных находок в базе исключений.

## Решение

Вариант 2. Находки группируются по паре «маршрут × вьюпорт»; для пары делается N визитов
(по умолчанию 3) в новом `BrowserContext` — без кэша, cookies и localStorage — со всеми
проверками: воспроизведению может понадобиться действие соседней проверки, например прокрутка
(BUG-07). Сбой навигации, появившийся при перепроверке, попадает в отчёт отдельной находкой (BUG-06). Находка сравнивается по отпечатку: хэш проверки, маршрута,
вьюпорта и цели: метод, путь без query и класс ответа для HTTP, правило и узлы для axe,
текст ошибки без номеров строк и хэшей сборки для консоли.

Вердикты: N из N — **подтверждено**; 0 из N — **не подтвердилось**; между — **нестабильно**.
Код выхода зависит только от подтверждённых.

Ретраи раннера (вариант 1) скрывают нестабильность: тест «прошёл со второго раза» и находка
исчезла. Здесь нестабильность остаётся в отчёте отдельной строкой — это тоже информация
для разработчика.

## Последствия

- Плюс: нестабильный запрос виден, но сборку не валит (мета-тест проверяет на `/api/recommendations`).
- Плюс: повторяются только пары «маршрут × вьюпорт», где есть находки.
- Минус: время прогона растёт с числом находок: на витрине с дефектами 57 с против 17 с на чистой (см. 05-testing).
- Минус: дефект, который проявляется реже чем в 1 из N+1 визитов, может не попасть в отчёт вовсе. Принято: такие дефекты ловит мониторинг, не приёмка.
