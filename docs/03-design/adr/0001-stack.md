# ADR-0001. Стек: Playwright + TypeScript для ShopProbe, FastAPI + PostgreSQL для витрины

Принято 2026-11-03.

**Контекст.** Инструменту нужен реальный браузер на разных вьюпортах, консоль, сеть и проверка
доступности. Витрине — фасетный каталог со счётчиками из базы.

**Варианты.** 1) Playwright на TypeScript + axe-core; витрина FastAPI + PostgreSQL + React.
2) Playwright для Python, один язык с бэкендом. 3) Lighthouse CI.

**Решение.** Вариант 1. `@axe-core/playwright` живёт в Node, e2e витрины тоже на Playwright Test —
одна версия Playwright на всё. Lighthouse ставит странице оценку и не умеет перепроверку, мне нужен
список находок с шагами. Фасеты — `GROUP BY` с условиями; интеграционные тесты на PostgreSQL,
чтобы `IN` и сортировка вели себя как в проде.

**Последствия.**
- Плюс: проверки, мета-тест и e2e на одном языке, Playwright закреплён версией в `package.json` (сейчас 1.64.1).
- В кейсе два рантайма, два набора линтеров и lock-файлов.
- Запуск через tsx дал сбой, которого тесты под Vitest не видели ([04](../../04-ai-development.md#что-ai-пропустил-до-ревью)).
