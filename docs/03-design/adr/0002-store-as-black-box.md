# ADR-0002. Витрина — чёрный ящик: только браузер и HTTP

Принято 2026-10-21.

**Контекст.** ShopProbe должен проверять любую витрину: чужой код, чужая сборка, чужой хостинг.

**Варианты.** 1) Браузер и HTTP по `BASE_URL` и маршрутам. 2) Плагин в сборку витрины.
3) Логи сервера и база витрины.

**Решение.** Вариант 1. Конфиг — единственная точка связи. Для демо правило то же: ShopProbe
не импортирует код витрины, режим дефектов узнаёт через публичный `GET /api/meta`, мета-тест
запускает CLI внешним процессом.

**Последствия.**
- Плюс: новая витрина подключается правкой `probe.config.ts`.
- Минус: шум HMR и расширений попадает в консоль, нужен фильтр по умолчанию (BUG-04).
- Минус: для авторизации и оплаты нужен отдельный модуль сценариев.
